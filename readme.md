
# SafeCampus: Campus Emergency Information System

A desktop application for managing and accessing campus emergency information.

## Features

- 🔐 User Login & Authentication
- 📞 Emergency Contacts Management
- 📋 Safety Information & Procedures
- ⚠️ Incident Reporting & Tracking
- 📊 Dashboard with Statistics
- 📝 Incident Logs — Filter, Export CSV, View Details
- 🚨 Emergency Alerts — Post and view announcements
- 👥 User Management — Admin/Staff only

## Technologies
- Python
- CustomTkinter
- MySQL
- mysql-connector-python
- Git & GitHub
